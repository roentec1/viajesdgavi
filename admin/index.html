🔗 Conexión Google Sheets (Apps Script)

Pega aquí la URL de tu Google Apps Script Web App. Al guardarla, el panel admin y este navegador usarán esa conexión de inmediato. Para que todos los visitantes del sitio vean los datos actualizados, también debes poner la misma URL en assets/js/config.js y volver a publicar.

URL activa:

Estado:

Cómo obtener la URL (paso a paso)

  1. Abre tu Google Sheet → Extensiones → Apps Script
  2. Pega el código de google-apps-script.js y guarda
  3. Implementar → Nueva implementación → Aplicación web
  4. Ejecutar como: Yo · Acceso: Cualquiera
  5. Copia la URL que termina en /exec y pégala arriba
  6. Clic en Guardar URL y luego Probar conexión

Para que el sitio público se actualice solo

1. Guarda la URL aquí (admin).
2. Clic en Descargar config.js (ya trae tu URL).
3. Sustituye el archivo assets/js/config.js del hosting por el descargado.
4. Listo: el portal principal leerá promociones, destinos y paquetes desde Google Sheets automáticamente.
